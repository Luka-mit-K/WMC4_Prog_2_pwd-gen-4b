# Password Generator
This Module enables a way of **generating a random password**.

It has the following parameters:
- ``passwordLength`` (type: ***number***),
- ``useSpecialCharacters`` (type: ***boolean***)

*passwordGenerator(passwordLength, useSpecialCharacters)*

**Example use:** ``passwordGenerator(8, true);``
